# Code of Conduct

This project is maintained by one person and used by musicians, artists and developers.
The rule is simple: treat everyone here the way you would want to be treated while
learning something new in public.

## Expected

- Be respectful and direct. Disagree with the code, not with the person.
- Assume good faith; ask before concluding.
- Keep discussions on the work. Personal attributes — origin, gender, age, disability,
  religion, orientation, appearance, experience level — are never a topic of criticism.
- Credit other people's work and ideas.

## Not accepted

- Harassment, insults, threats, sexualised language or imagery, trolling, or sustained
  disruption of a discussion.
- Publishing other people's private information (including health data such as the
  heart-rate values the app's diagnostics text contains).

## Enforcement

Reports go to the contact address in `SECURITY.md` with "Conduct" in the subject. The
maintainer will read every report, keep it confidential, and respond. Consequences range
from a request to change behaviour to removal from the project's spaces (issues, pull
requests, discussions), at the maintainer's judgement.

This text is adapted in spirit from the Contributor Covenant (v2.1); it is deliberately
shorter so that it is read.
