TouchDesigner: one CHOP channel per body signal

TouchDesigner's OSC In CHOP turns every address it hears into a named channel. Echoel sends the body as OSC, so a heartbeat, a breath phase and a coherence value become CHOP channels you patch into anything — a Noise TOP's period, a Geometry COMP's scale, a light's intensity.

1. Receive

  1. Add an OSC In CHOP. Network Port: 8000 (Echoel's default; any free port works if you change it on both ends). Leave the address filter open for now.
  2. In Echoel: Routing ▸ OSC, host = this computer's IP, port 8000; patchbay Body → OSC out.
  3. Put a finger on the camera. Within a couple of seconds the CHOP grows a channel per address that has been measured — pulse first, breath as soon as the breath estimator has a cycle, coherence after about sixteen accepted beats.

A channel that never appears is not a connection fault: Echoel sends an address only while its value is measured. The demo body sends everything and announces itself on /echoelmusic/bio/synthetic (1), so you can wire the network with the demo and know when the real performer takes over (0).

2. Select and shape

  1. Add a Select CHOP after the OSC In and name the channels you actually use — for a first patch *breath/phase, *heart/bpm, *coherence. Never select *motion* or *eeg*: those addresses exist in the sender and are never sent.
  2. Add a Lag CHOP (or Filter) on the pulse: the beat rate updates roughly once a second, and a lag of 0.5–1 s turns steps into a glide.
  3. Add a Math CHOP to range: bpm 60–120 → 0–1, breath phase is already 0–1, coherence is already 0–1.

3. Drive something

  • Breath → scale: reference op('select1')['breath/phase'] (or the exact channel name your CHOP shows) in a Geometry COMP's scale — the object breathes with the performer.
  • Pulse → period: bpm into a Noise TOP's period or a Speed CHOP — faster body, faster texture.
  • Coherence → sharpness: coherence into a Blur TOP's filter size, inverted — a settling performer brings the image into focus.
  • Beat → trigger: the event/heartbeat channel pulses per beat; feed it to a Trigger CHOP for an envelope on every heartbeat.

Frame-rate note

Continuous addresses arrive about once a second; events per beat. TouchDesigner cooks at your project rate regardless — put the smoothing in a Lag or Filter CHOP rather than expecting the source to interpolate. That is deliberate on Echoel's side: it sends measurements, not animation.

Also from the same phone

The same performer's pulse can drive DMX fixtures in your rig over Art-Net or sACN, and a spatial object over ADM-OSC, at the same time as the CHOP feed. Ports, the full address list and the DMX channel map are on the integrations page.
