Reaper: play a track or a plug-in from your pulse over OSC

Reaper learns any OSC address the way it learns a MIDI controller: open the learn window, move the source, click. Echoel is the source. Ten minutes from an empty project to a filter that opens with your breath.

Before you start

  • Phone and computer on the same network (a phone hotspot works; latency is a few milliseconds on a LAN).
  • The computer's IP address — System Settings ▸ Network on a Mac, ipconfig on Windows.
  • A bio source running in Echoel: camera pulse (finger on the lens) or a Bluetooth chest strap. The demo body works for wiring up, and announces itself on /echoelmusic/bio/synthetic so you cannot mistake it for a performer later.

1. Tell Reaper to listen

  1. Options ▸ Preferences ▸ Control/OSC/web ▸ Add.
  2. Control surface mode: OSC (Open Sound Control). Pattern config: Default is fine — learn does not need a pattern file.
  3. Mode: Local port (receive only). Local listen port: 8000, the port Echoel sends to by default. If something else already owns 8000, pick another and change it in Echoel too.
  4. Leave Allow binding messages to REAPER actions and FX learn ticked. OK.

2. Point Echoel at Reaper

  1. In Echoel open Routing, section OSC: host = the computer's IP, port = the port from step 1.
  2. In the patchbay connect Body → OSC out. The feed starts as soon as a value is measured; nothing is sent while nothing is measured.

3. Learn a parameter

  1. Insert any plug-in on a track — ReaEQ, a synth, anything with a knob — and open its window.
  2. Click Param ▸ Learn (or Param ▸ FX parameter list ▸ Learn) and pick the parameter.
  3. Breathe. Reaper shows the incoming address — /echoelmusic/bio/breath/phase for the breath, /echoelmusic/bio/heart/bpm for the pulse — the moment Echoel sends it. Click OK.
  4. Set the parameter's range under Param ▸ Parameter modulation/MIDI link if 0–1 should map to less than the full travel.

Actions learn the same way: Actions ▸ Show action list ▸ Add under Shortcuts for selected action, then trigger the source. The per-beat bang /echoelmusic/bio/event/heartbeat is the one to bind to an action — a marker, a sample trigger, a transport toggle.

Which address for what

WantBindWhy
a slow, continuous sweep/echoelmusic/bio/breath/phase0→1 over each breath, smooth, always present once breath is measured
a value that follows effort/echoelmusic/bio/heart/bpm40–200; set a range in Reaper so 60–120 covers the travel
a value that follows settling/echoelmusic/bio/coherence0–1; appears after ~16 beats, so map it to something that can wait
a trigger on every beat/echoelmusic/bio/event/heartbeatan action, a sampler, a marker

Prefer MIDI?

Route Music → MIDI out instead and Reaper sees a device called Echoelmusic — over the network through Apple's Network MIDI session (Audio MIDI Setup ▸ MIDI Studio ▸ Network on a Mac), over USB through IDAM, or over Bluetooth. Arm a track with that input and the body-composed take records as notes. Switch on MPE note layout in Routing for a per-note synth.

If nothing arrives

  • Reaper's learn window shows nothing: check the port matches on both ends, and that the phone shows a measured pulse — no value, no packet.
  • An address you expected is missing: it has not been measured yet. Coherence takes ~16 beats; HRV needs a clean contact.
  • Values freeze when the finger slips: expected. Echoel holds silence rather than sending zero; your parameter keeps its last value.

The full address list, ports and the DMX map are on the integrations page.
