    2  // Echoel — GMMW VV-4 (founder 2026-10-08, "own footage inside own engine"): the law gate that comes
    3  // BEFORE any door shows a person's own video in the visuals. `FlashGuard` budgets the GENERATED
    4  // looks — each one's flash rate is derived from its shader — but footage is not ours: a clip can
    5  // hold a strobe, a lightning storm or a club light at 10 Hz, and no budget written in advance can
    6  // cover it. The seed reader samples at most four frames a second, so it cannot certify a strobe
    7  // either. This type watches the frames that are actually SHOWN and caps the layer's gain.
    8  //
    9  // ⭐ WHAT IT WATCHES. The caller hands a grid of CELL luminances (`VideoLayerMath.regionMeans`,
   10  // 8 × 8 by `VideoLayerMath.flashCellsPerSide`). Every channel below is a hysteresis on one signal,
   11  // and the cap engages when any one of them holds `engageTransitions` (5) inside one second:
   12  // · WINDOWS on the footage: every 2 × 2 and 4 × 4 square of cells at half its own stride (so they
   13  //   overlap) and the whole frame, at a quarter of the WCAG step. A WCAG flash counts when the
   14  //   flashing area within any one 10° field is large enough, and that field can sit anywhere — on a
   15  //   block corner, across two blocks (review of VV-4: fixed blocks diluted a corner flash four times
   16  //   and never added up two neighbours taking turns). The whole frame also carries a small picture
   17  //   (the floating card), where the 10° field is larger than the layer.
   18  // · CELLS on the footage, each at the whole step. A window adds its cells up, so cells swinging
   19  //   AGAINST each other cancel in it — a checkerboard or one-cell stripes reversing at 10 Hz never
   20  //   moved a single window (second review of VV-4). A cell alone cannot cancel.
   21  // · CELLS as SHOWN — the gain the layer has now times the cell — at the whole step: the viewer's own
   22  //   count. The gain moves too, and only these channels see what that does: the climb back is a rise
   23  //   of its own, and it turns footage that keeps falling (one movement to every footage channel) into
   24  //   a fall, a rise and a fall on the screen (second review: six transitions in a second, which no
   25  //   lowered count on the footage could catch — the first draft of this fix had one and still showed
   26  //   six).
   27  //
   28  // ⭐ WHAT IT GUARANTEES, and the arithmetic behind it (WCAG 2.3.1, the numbers are `FlashGuard`'s):
   29  // · A TRANSITION is a channel's signal moving its step against its last extreme (hysteresis, so a
   30  //   slow fade is one transition, not many); before its first, against its own lowest and highest, so
   31  //   a strobe that starts mid-swing counts from its first full swing. Two opposing ones are a flash.
   32  //   Every step carries `roundingAllowance`, so a move of exactly the step counts. A direction whose
   33  //   last transition is a whole second old is forgotten, its extreme kept as the reference: a step off
   34  //   a level settled long ago is a change of its own, not the rest of a rise that ended before the
   35  //   counting window (second review: such a step started a strobe uncounted, and six showed).
   36  // · When any channel holds five transitions inside one second, the gain drops to `engagedGain`
   37  //   (0.05) on that frame. While engaged no pixel the layer adds can move by 0.05, half the WCAG
   38  //   step — nothing it shows can be a flash at all.
   39  // · A flash covering any rectangle at least two cells wide and tall covers some cell completely, and
   40  //   that cell's shown channel counts what is shown there — with the gain of the frame before, so at
   41  //   most one climb step behind. So at most five transitions show in any second, two and a half
   42  //   flashes, under the three WCAG allows — the cap's own edge included. That is the argument; the
   43  //   transcription measured it too, at five, over the review's inputs and random and directed ones.
   44  //   A smaller flash is counted on the footage only (a quarter of a 2 × 2 window at a quarter step:
   45  //   over-counted, the safe side), not on the shown signal.
   46  // · It climbs back only after `holdSeconds` with no channel at the count, at `releasePerSecond`,
   47  //   stepped through `FlashGuard.maxDelta` and only on a frame that advanced its clock, so neither a
   48  //   stall nor a repeated frame turns the climb into a jump. A source that goes on strobing never
   49  //   releases it; a slower flash after a strobe does (the first version held a 1.9 Hz flash at 0.05
   50  //   for good, because it engaged at four while the gain was below 1).
   51  //
   52  // ⭐ IT KEEPS ITS OWN CLOCK. Each frame advances it by the source's elapsed time, clamped to
   53  // `shortestFrameSeconds…longestFrameSeconds`. A REPEATED time advances it by nothing — a 24 fps clip
   54  // on a 120 Hz display passes each media time five times, and the first version's 1/240 s for each
   55  // repeat ran its clock 40 % fast, so a 2.6 Hz flash read as under the count and played uncapped
   56  // (second review). A time that goes BACK — a seek or a loop on a media clock — or NaN advances it by
   57  // the shortest frame: a frame is never dropped from counting and the gain is never reset, so a loop
   58  // back into a strobe is counted as it plays.
   59  // ⚠️ PASS THE DISPLAY CLOCK. A media clock is read at rate 1: at a faster playback rate every
   60  // frequency looks slower by that rate and the limiter counts too little. The door (VV-6) inherits
   61  // this as a requirement, not a preference.
   62  //
   63  // ⚠️ WHAT IT IS NOT, so nobody reads more into it:
   64  // · It caps the LAYER, not the screen. The generated field under it has its own budget
   65  //   (`FlashGuard.fieldBudgets`); the sum of the two is a device probe, not a claim here.
   66  // · It engages at two and a half flashes a second ON PURPOSE, below the three WCAG allows, to
   67  //   leave room for its own edge. So legal footage flashing between about 2 and 3 Hz (beat lighting
   68  //   at 120–180 BPM) is dimmed, and a pulse near 2 Hz can be, depending on frame timing and on how
   69  //   unevenly it swings. That is the safe side; a steady flash at 1.9 Hz is never touched.
   70  // · The windows' quarter step dims some LEGAL footage on the same side: a whole-picture flicker of
   71  //   a quarter step or more at 2.5 Hz and faster (measured: 0.02 untouched, 0.025 capped), a
   72  //   high-contrast edge shaken by a fraction of a cell, a textured pan of about half a picture width a
   73  //   second. A single edge panning across is one transition per cell at any speed and is never
   74  //   touched.
   75  // · It ignores WCAG's dark-state exemption (two states both above 0.80 are not a flash): counting
   76  //   them too is the safe direction, and a cap on a bright shimmer costs little.
   77  // · It sees cell MEANS, not shapes: a pattern with a period of two cells set half a cell off the
   78  //   grid keeps every cell mean flat while it reverses, and the grid cannot see it at all; a line an
   79  //   eighth of a cell wide counts only once its share of some window reaches the quarter step.
   80  // · It trusts the cells it is handed. `VideoLayerSlot` (VV-5b) estimates each from 2 × 2 point

  204      public mutating func step(time: Double, cells: [Double], cellsPerSide: Int) -> Double {
  205          guard cellsPerSide > 0 else { return gain }
  206          let (cellCount, overflow) = cellsPerSide.multipliedReportingOverflow(by: cellsPerSide)
  207          guard !overflow, cells.count == cellCount else { return gain }
  208          let dt = advanceClock(to: time)
  209          if cellsPerSide != side { layOut(cellsPerSide) }
  210  
  211          let windowStart = clock - Self.windowSeconds
  212          var busiest = 0
  213  
  214          var frameSum = 0.0
  215          var finiteCells = 0
  216          for value in cells where value.isFinite {
  217              frameSum += Swift.min(1, Swift.max(0, value))
  218              finiteCells += 1
  219          }
  220          if finiteCells > 0 {
  221              if wholeFrame.registers(frameSum / Double(finiteCells), at: clock) { wholeFrame.mark(clock) }
  222              busiest = Swift.max(busiest, wholeFrame.count(after: windowStart))
  223          }
  224          for index in channels.indices {
  225              var windowSum = 0.0
  226              var usable = true
  227              for cell in windowCells[index] {
  228                  let value = cells[cell]
  229                  guard value.isFinite else { usable = false; break }
  230                  windowSum += Swift.min(1, Swift.max(0, value))
  231              }
  232              guard usable else { continue }
  233              if channels[index].registers(windowSum / Double(windowCells[index].count), at: clock) {
  234                  channels[index].mark(clock)
  235              }
  236              busiest = Swift.max(busiest, channels[index].count(after: windowStart))
  237          }
  238          for cell in cellChannels.indices {
  239              let value = cells[cell]
  240              guard value.isFinite else { continue }
  241              let level = Swift.min(1, Swift.max(0, value))
  242              if cellChannels[cell].registers(level, at: clock) { cellChannels[cell].mark(clock) }
  243              // What this cell shows with the gain the layer has now — before this frame decides.
  244              if shownChannels[cell].registers(gain * level, at: clock) { shownChannels[cell].mark(clock) }
  245              busiest = Swift.max(busiest, cellChannels[cell].count(after: windowStart),
  246                                  shownChannels[cell].count(after: windowStart))
  247          }
  248  
  249          if busiest >= Self.engageTransitions {
  250              gain = Self.engagedGain
  251              quietSince = nil
  252          } else {
  253              let since = quietSince ?? clock
  254              quietSince = since
  255              if clock - since >= Self.holdSeconds, gain < 1, dt > 0 {
  256                  gain = Swift.min(1, gain + FlashGuard.maxDelta(perSecond: Self.releasePerSecond, dt: dt))
  257              }
  258          }
  259          return gain
  260      }

   35      /// The relative luminance of an sRGB colour whose components are 0…1. Non-finite components
   36      /// read as 0 and every component is clamped first, so the answer is always 0…1.
   37      public static func relativeLuminance(red: Double, green: Double, blue: Double) -> Double {
   38          func linear(_ component: Double) -> Double {
   39              let c = component.isFinite ? Swift.min(1, Swift.max(0, component)) : 0
   40              return c <= 0.04045 ? c / 12.92 : Foundation.pow((c + 0.055) / 1.055, 2.4)
   41          }
   42          let r: Double = redWeight * linear(red)
   43          let g: Double = greenWeight * linear(green)
   44          let b: Double = blueWeight * linear(blue)
   45          return Swift.min(1, r + g + b)

  324      static func shownLuminance(y: Double, cb: Double, cr: Double, videoRange: Bool) -> Double {
  325          let luma: Double
  326          let blueDifference: Double
  327          let redDifference: Double
  328          if videoRange {
  329              luma = ((y - 16.0 / 255.0) * (255.0 / 219.0)).clamped(to: 0...1)
  330              blueDifference = (cb - 128.0 / 255.0) * (255.0 / 224.0)
  331              redDifference = (cr - 128.0 / 255.0) * (255.0 / 224.0)
  332          } else {
  333              luma = y.clamped(to: 0...1)
  334              blueDifference = cb - 128.0 / 255.0
  335              redDifference = cr - 128.0 / 255.0
  336          }
  337          let red = (luma + crToRed * redDifference).clamped(to: 0...1)
  338          let green = (luma - cbToGreen * blueDifference - crToGreen * redDifference).clamped(to: 0...1)
  339          let blue = (luma + cbToBlue * blueDifference).clamped(to: 0...1)
  340          return VideoLayerMath.relativeLuminance(red: red, green: green, blue: blue)
  341      }
