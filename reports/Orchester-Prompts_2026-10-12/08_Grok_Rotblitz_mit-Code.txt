AUFTRAG FÜR GROK: Rot-Blitz-Kanal angreifen: kann ein roter Blitz trotzdem durch? (Stand a678d9959)

Deine Spur: ein fertiges Sicherheits-Stück angreifen und den konkreten Eingabefall finden, bei dem es versagt.
Nicht deine Spur: Code, ein eigener Gegenentwurf, die Helligkeits-Prüfung an sich (die ist zweimal geprüft), die Video-Uhr.

WORUM ES GEHT
- WCAG 2.3.1 kennt zwei Blitz-Arten: allgemeine (Helligkeit) und rote (gesättigtes Rot). Der Begrenzer für eigenes Video zählte nur die Helligkeit. Seit diesem Stand zählt er zusätzlich ein Rot-Signal je Zelle: lineares R − G − B, unten auf 0 begrenzt; Schritt 20/320 je Zelle, ein Viertel davon je Fenster. Bei 5 Wechseln in einer Sekunde in irgendeinem Kanal fällt die Ebene auf 0,05.
- Bewusst weggelassen: der Sättigungs-Test von WCAG (ein Zustand mit R/(R+G+B) ≥ 0,8). Ohne ihn wird MEHR gezählt, nicht weniger.
- Annahme im Code: Die Ebene wird mit (Regler × Begrenzer-Gain) multipliziert, und das wirkt auf das Rot-Signal linear (auf Helligkeit genauso).
- Die Zellen sind Mittelwerte aus 2 × 2 Punktproben je Zelle auf einem 8 × 8-Gitter, aus dem 4:2:0-Puffer so dekodiert, wie der Shader es zeigt (BT.709).

STELLEN (stehen alle unten im Code)
- VideoFlashLimiter.swift: Kopf Z. 1–110 (die Begründung), Konstanten, Channel, Signal, step(), layOut()
- VideoLayerMath.swift Z. 30–60: relativeLuminance, redFlashSignal, linearComponent
- VideoLayerSlot.swift Z. 273–320 (ingest + count) und Z. 330–440 (Dekodierung, Zellen)

FRAGEN
1. Gibt es einen roten Blitz (Farben, Fläche, Frequenz, Startphase), der WCAG verletzt und bei dem kein Rot-Kanal fünf Wechsel in einer Sekunde zählt? Rechne mit den echten Schwellen und der Fenster-Logik.
2. Hält die Begründung „Gain 0,05 liegt unter dem Rot-Schritt 0,0625, also kann die gedeckelte Ebene keinen roten Blitz zeigen“, wenn die Ebene über einem Bild liegt, das selbst rot ist (Mischung in Gamma- oder in linearem Licht)? Was zeigt der Code darüber, wie die Ebene gemischt wird?
3. Kann die Dekodierung (Video-Range, Clamp, 4:2:0-Chroma-Unterabtastung, Punktproben statt echter Mittelwerte) das Rot-Signal so unterschätzen, dass ein echter roter Blitz unter der Schwelle bleibt?
4. Wenn redCells die falsche Länge hat, zählt nur die Helligkeit — gibt es im gezeigten Code einen Weg, auf dem das in Produktion passiert?

     4  // looks — each one's flash rate is derived from its shader — but footage is not ours: a clip can
     5  // hold a strobe, a lightning storm or a club light at 10 Hz, and no budget written in advance can

    10  // 8 × 8 by `VideoLayerMath.flashCellsPerSide`). Every channel below is a hysteresis on one signal,
    11  // and the cap engages when any one of them holds `engageTransitions` (5) inside one second:
    12  // · WINDOWS on the footage: every 2 × 2 and 4 × 4 square of cells at half its own stride (so they
    13  //   overlap) and the whole frame, at a quarter of the WCAG step. A WCAG flash counts when the
    14  //   flashing area within any one 10° field is large enough, and that field can sit anywhere — on a
    15  //   block corner, across two blocks (review of VV-4: fixed blocks diluted a corner flash four times
    16  //   and never added up two neighbours taking turns). The whole frame also carries a small picture
    17  //   (the floating card), where the 10° field is larger than the layer.
    18  // · CELLS on the footage, each at the whole step. A window adds its cells up, so cells swinging
    19  //   AGAINST each other cancel in it — a checkerboard or one-cell stripes reversing at 10 Hz never
    20  //   moved a single window (second review of VV-4). A cell alone cannot cancel.
    21  // · CELLS as SHOWN — the gain the layer has now times the cell — at the whole step: the viewer's own
    22  //   count. The gain moves too, and only these channels see what that does: the climb back is a rise
    23  //   of its own, and it turns footage that keeps falling (one movement to every footage channel) into
    24  //   a fall, a rise and a fall on the screen (second review: six transitions in a second, which no

    37  //   slow fade is one transition, not many); before its first, against its own lowest and highest, so

    43  // · When any channel holds five transitions inside one second, the gain drops to `engagedGain`
    44  //   (0.05) on that frame. While engaged no pixel the layer adds can move by 0.05, half the WCAG
    45  //   step — nothing it shows can be a flash at all.

    47  //   that cell's shown channel counts what is shown there (its red shown channel too: the engaged
    48  //   gain, 0.05, is under the red step as well) — with the gain of the frame before, so at

   139      /// One signal's hysteresis and the times of its last `engageTransitions` transitions.
   140      private struct Channel: Sendable {
   141          let threshold: Double
   142          var seeded = false
   143          var extreme = 0.0
   144          var lowest = 0.0
   145          var highest = 0.0
   146          var direction = 0
   147          var times = [Double](repeating: -Double.infinity, count: VideoFlashLimiter.engageTransitions)
   148          var next = 0
   149  
   150          init(step: Double) {
   151              threshold = step * (1 - VideoFlashLimiter.roundingAllowance)
   152          }
   153  
   154          /// Whether `value`, seen at `now`, completes a transition (hysteresis against the extreme
   155          /// since the last one; before the first, against the lowest and highest seen). A direction
   156          /// whose last transition is a whole counting window old is forgotten, its extreme kept as
   157          /// the reference — so a step off a level settled long ago is a change of its own.
   158          mutating func registers(_ value: Double, at now: Double) -> Bool {
   159              let last = times[(next + VideoFlashLimiter.engageTransitions - 1) % VideoFlashLimiter.engageTransitions]
   160              if direction != 0, last <= now - VideoFlashLimiter.windowSeconds {
   161                  direction = 0
   162                  lowest = extreme
   163                  highest = extreme
   164              }
   165              guard seeded else {
   166                  seeded = true
   167                  extreme = value
   168                  lowest = value
   169                  highest = value
   170                  return false
   171              }
   172              switch direction {
   173              case 1:
   174                  if value > extreme { extreme = value; return false }
   175                  guard value <= extreme - threshold else { return false }
   176                  direction = -1
   177              case -1:
   178                  if value < extreme { extreme = value; return false }
   179                  guard value >= extreme + threshold else { return false }
   180                  direction = 1
   181              default:

   183                  highest = Swift.max(highest, value)
   184                  guard highest - lowest >= threshold else { return false }
   185                  direction = value >= highest ? 1 : -1
   186              }
   187              extreme = value
   188              return true
   189          }

   226          /// this signal's channels holds after `windowStart`. `gain` is the layer's gain before this
   227          /// frame decides: the shown channels count what the screen shows with it.
   228          mutating func feed(_ values: [Double], windowCells: [[Int]], gain: Double,
   229                             at clock: Double, after windowStart: Double) -> Int {
   230              var busiest = 0
   231              var frameSum = 0.0
   232              var finiteCells = 0
   233              for value in values where value.isFinite {
   234                  frameSum += Swift.min(1, Swift.max(0, value))
   235                  finiteCells += 1
   236              }
   237              if finiteCells > 0 {
   238                  if wholeFrame.registers(frameSum / Double(finiteCells), at: clock) { wholeFrame.mark(clock) }
   239                  busiest = Swift.max(busiest, wholeFrame.count(after: windowStart))
   240              }
   241              for index in windows.indices {
   242                  var windowSum = 0.0
   243                  var usable = true
   244                  for cell in windowCells[index] {
   245                      let value = values[cell]
   246                      guard value.isFinite else { usable = false; break }
   247                      windowSum += Swift.min(1, Swift.max(0, value))
   248                  }
   249                  guard usable else { continue }
   250                  if windows[index].registers(windowSum / Double(windowCells[index].count), at: clock) {
   251                      windows[index].mark(clock)
   252                  }
   253                  busiest = Swift.max(busiest, windows[index].count(after: windowStart))
   254              }
   255              for cell in cells.indices {
   256                  let value = values[cell]
   257                  guard value.isFinite else { continue }
   258                  let level = Swift.min(1, Swift.max(0, value))
   259                  if cells[cell].registers(level, at: clock) { cells[cell].mark(clock) }
   260                  // What this cell shows with the gain the layer has now — before this frame decides.
   261                  if shown[cell].registers(gain * level, at: clock) { shown[cell].mark(clock) }
   262                  busiest = Swift.max(busiest, cells[cell].count(after: windowStart),
   263                                      shown[cell].count(after: windowStart))
   264              }
   265              return busiest
   266          }

   282      /// Feeds one shown frame and returns the gain. `cells` are its cell luminances, 0…1, row-major in
   283      /// a `cellsPerSide × cellsPerSide` grid; `redCells` the same cells' red signal
   284      /// (`VideoLayerMath.redFlashSignal`), or nil where the caller has no colour — then only the
   285      /// luminance counts, and a footage door must never pass nil (`UserFootageCannotStrobeTests`).
   286      /// A luminance grid of the wrong size changes nothing; a red grid of the wrong size is left out
   287      /// and the luminance still counts. A non-finite cell leaves out its own channels and the windows
   288      /// it belongs to.
   289      @discardableResult
   290      public mutating func step(time: Double, cells: [Double], redCells: [Double]?, cellsPerSide: Int) -> Double {
   291          guard cellsPerSide > 0 else { return gain }
   292          let (cellCount, overflow) = cellsPerSide.multipliedReportingOverflow(by: cellsPerSide)
   293          guard !overflow, cells.count == cellCount else { return gain }
   294          let dt = advanceClock(to: time)
   295          if cellsPerSide != side { layOut(cellsPerSide) }
   296  
   297          let windowStart = clock - Self.windowSeconds
   298          var busiest = luminance.feed(cells, windowCells: windowCells, gain: gain,
   299                                       at: clock, after: windowStart)
   300          if let redCells, redCells.count == cellCount {
   301              busiest = Swift.max(busiest, red.feed(redCells, windowCells: windowCells, gain: gain,
   302                                                    at: clock, after: windowStart))
   303          }
   304  
   305          if busiest >= Self.engageTransitions {
   306              gain = Self.engagedGain
   307              quietSince = nil
   308          } else {
   309              let since = quietSince ?? clock
   310              quietSince = since
   311              if clock - since >= Self.holdSeconds, gain < 1, dt > 0 {
   312                  gain = Swift.min(1, gain + FlashGuard.maxDelta(perSecond: Self.releasePerSecond, dt: dt))
   313              }
   314          }
   315          return gain
   316      }

   353                          for c in column..<(column + size) { members.append(r * cellsPerSide + c) }
   354                      }
   355                      windows.append(members)
   356                  }
   357              }

   359          }

   361          let cellCount = cellsPerSide <= Self.maxCellsPerSide ? cellsPerSide * cellsPerSide : 0

   341      /// The sRGB colour, each 0…1, the SHADER shows for one Y/Cb/Cr sample: range expansion, BT.709
   342      /// matrix and clamp exactly as in the MSL footage branch. Both measures above read it.
   343      private static func shownRGB(y: Double, cb: Double, cr: Double,
   344                                   videoRange: Bool) -> (red: Double, green: Double, blue: Double) {
   345          let luma: Double
   346          let blueDifference: Double
   347          let redDifference: Double
   348          if videoRange {
   349              luma = ((y - 16.0 / 255.0) * (255.0 / 219.0)).clamped(to: 0...1)

   351              redDifference = (cr - 128.0 / 255.0) * (255.0 / 224.0)
   352          } else {

   354              blueDifference = cb - 128.0 / 255.0

   356          }

   358          let green = (luma - cbToGreen * blueDifference - crToGreen * redDifference).clamped(to: 0...1)
   359          let blue = (luma + cbToBlue * blueDifference).clamped(to: 0...1)
   360          return (red, green, blue)
   361      }

   383      /// The one sampling grid both measures read, so they can never sample different points.
   384      private static func cells(of buffer: CVPixelBuffer, samples: inout [Double],
   385                                measure: (Double, Double, Double, Bool) -> Double) -> [Double]? {
   386          let videoRange: Bool
   387          switch CVPixelBufferGetPixelFormatType(buffer) {
   388          case kCVPixelFormatType_420YpCbCr8BiPlanarFullRange: videoRange = false
   389          case kCVPixelFormatType_420YpCbCr8BiPlanarVideoRange: videoRange = true
   390          default: return nil
   391          }

   393                CVPixelBufferLockBaseAddress(buffer, .readOnly) == kCVReturnSuccess else { return nil }
   394          defer { CVPixelBufferUnlockBaseAddress(buffer, .readOnly) }
   395          let lumaWidth = CVPixelBufferGetWidthOfPlane(buffer, 0)
   396          let lumaHeight = CVPixelBufferGetHeightOfPlane(buffer, 0)
   397          let chromaWidth = CVPixelBufferGetWidthOfPlane(buffer, 1)
   398          let chromaHeight = CVPixelBufferGetHeightOfPlane(buffer, 1)
   399          let lumaStride = CVPixelBufferGetBytesPerRowOfPlane(buffer, 0)
   400          let chromaStride = CVPixelBufferGetBytesPerRowOfPlane(buffer, 1)
   401          guard lumaWidth > 0, lumaHeight > 0, chromaWidth > 0, chromaHeight > 0,
   402                lumaStride >= lumaWidth, chromaStride >= chromaWidth * 2,
   403                let lumaBase = CVPixelBufferGetBaseAddressOfPlane(buffer, 0),
   404                let chromaBase = CVPixelBufferGetBaseAddressOfPlane(buffer, 1) else { return nil }
   405          let side = samplesPerSide
   406          if samples.count != side * side { samples = [Double](repeating: 0, count: side * side) }
   407          for row in 0..<side {
   408              let lumaY = Swift.min(lumaHeight - 1, (2 * row + 1) * lumaHeight / (2 * side))
   409              let chromaY = Swift.min(chromaHeight - 1, lumaY * chromaHeight / lumaHeight)
   410              for column in 0..<side {
   411                  let lumaX = Swift.min(lumaWidth - 1, (2 * column + 1) * lumaWidth / (2 * side))
   412                  let chromaX = Swift.min(chromaWidth - 1, lumaX * chromaWidth / lumaWidth)
   413                  let lumaByte = lumaBase.load(fromByteOffset: lumaY * lumaStride + lumaX, as: UInt8.self)
   414                  let chromaOffset = chromaY * chromaStride + chromaX * 2
   415                  let cbByte = chromaBase.load(fromByteOffset: chromaOffset, as: UInt8.self)
   416                  let crByte = chromaBase.load(fromByteOffset: chromaOffset + 1, as: UInt8.self)
   417                  samples[row * side + column] = measure(Double(lumaByte) / 255,
   418                                                         Double(cbByte) / 255,
   419                                                         Double(crByte) / 255,
   420                                                         videoRange)
   421              }
   422          }
   423          return VideoLayerMath.regionMeans(samples, side: side, blocks: VideoLayerMath.flashCellsPerSide)
   424      }
